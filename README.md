# RK Insight Analytics Website

Professional static website for RK Insight Analytics.

## Files
- `index.html` — website content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile menu, animations and current year

## Publish with GitHub Pages
1. Upload all three files to the root of the `rkinsightanalytics` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.
5. After GitHub publishes the site, add the custom domain:
   `rkinsightanalytics.co.uk`
